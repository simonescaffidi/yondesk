Features

As powerful as the big names, transparent by design

Everything you expect from a professional remote support tool.

🖥️ Real-time screen control

View and control the remote desktop with minimal latency. Adaptive quality (low/balanced/high) based on bandwidth.

🔀 Multi-monitor

Switch between the remote computer's monitors and choose which one to view.

📁 Two-way file transfer

Drop files into the session: they travel over the encrypted peer-to-peer channel, never through a server or cloud.

💬 Session chat

Built-in messaging to coordinate with the user without external tools.

📋 Shared clipboard

Copy on one computer, paste on the other — handy for passwords, links and commands.

🛡️ Unattended access (opt-in)

For your servers and PCs: you enable it on the device, with a dedicated password and an always-visible icon/banner showing access is enabled.

🔒 Security

End-to-end encryption (DTLS-SRTP), per-session password, mandatory consent on the assisted side, lockout after failed attempts.

🌐 Cross-platform

Windows, macOS, Linux (desktop app), Android and iOS (mobile app) and a web client with no install.

🔗 Direct connection

WebRTC with STUN/TURN: peer-to-peer when possible, relay when NAT traversal is needed.
