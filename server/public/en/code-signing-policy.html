Code signing policy

This page describes how Yondesk binaries are signed, who is responsible for them and what the app does on your device. Yondesk is free software under the MIT license: all source code is public on GitHub.

Signing

  • Windows: Free code signing provided by SignPath.io, certificate by SignPath Foundation.
  • macOS: Developer ID signature and Apple notarization (SCAFFIDI DOMIANELLO SIMONE, team 323D574J2W).
  • Android: APK signed with the project's release key.

Signed binaries are built only by GitHub Actions from the source code in the public repository, never on a personal computer. A release starts only if the automated tests (real sessions on Windows, macOS, Linux, Android and iOS) pass for the same commit, and every signing request needs manual approval.

Roles

  • Committers and reviewers: Simone Scaffidi Domianello (@simonescaffidi), repository owner. Changes proposed by anyone else go through a pull request reviewed by him.
  • Approvers: Simone Scaffidi Domianello (@simonescaffidi).

Access to GitHub and SignPath is protected by multi-factor authentication.

Privacy

This program will not transfer any information to other networked systems unless specifically requested by the user or the person installing or operating it. When you start the app it connects to the Yondesk signaling server to obtain an ID and to put the two devices in touch; screen, files, chat and input travel end-to-end encrypted and the server cannot read them. If the two networks cannot reach each other directly, the encrypted traffic goes through a Yondesk relay. Details in the Privacy Policy.

What the app does on the device

  • No session starts without consent: the assisted person must accept every request, and a notice stays visible for the whole session.
  • Unattended access is off. It can only be enabled in the settings, with a dedicated password, and always shows an indicator.
  • The app does not change the system configuration. On macOS it asks for the Screen Recording and Accessibility permissions through the system dialogs.

Uninstalling

  • Windows: Settings → Apps → Installed apps → Yondesk → Uninstall. The Portable version is removed by deleting the file.
  • macOS: drag Yondesk from the Applications folder to the Trash.
  • Linux: sudo apt remove yondesk; the AppImage is removed by deleting the file.
  • Android: long-press the icon → Uninstall.
