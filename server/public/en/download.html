Windows — first launch. The app isn't signed yet, so SmartScreen may show a blue warning (“Windows protected your PC”). It's not a virus: it's Microsoft's check on apps that aren't widely distributed yet. To open it:
  1. Click More info.
  2. Click Run anyway.
  3. Tip: use the Portable build, which runs without installing anything.
macOS, first launch. The app is signed and verified by Apple (notarized): it opens with a double click, macOS only asks for confirmation because it was downloaded from the internet. Drag Yondesk into the Applications folder and open it. To receive assistance, grant the Screen Recording and Accessibility permissions when the app asks.
Direct downloads. Files are served from the official GitHub releases (always the latest version). If a link errors out, the build is still publishing: retry in a few minutes. The web client is already fully functional.
