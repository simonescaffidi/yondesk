Code signing policy

Questa pagina descrive come vengono firmati i programmi Yondesk, chi ne è responsabile e cosa fa l'app sul tuo dispositivo. Yondesk è software libero con licenza MIT: tutto il codice è pubblico su GitHub.

Firma dei programmi

  • Windows: Free code signing provided by SignPath.io, certificate by SignPath Foundation.
  • macOS: firma Developer ID e notarizzazione Apple (SCAFFIDI DOMIANELLO SIMONE, team 323D574J2W).
  • Android: APK firmato con la chiave di rilascio del progetto.

I programmi firmati sono costruiti solo da GitHub Actions a partire dal codice del repository pubblico, mai da un computer personale. Una release parte solo se le prove automatiche (sessioni reali su Windows, macOS, Linux, Android e iOS) sono superate per lo stesso commit, e ogni firma richiede un'approvazione manuale.

Ruoli

  • Autori e revisori: Simone Scaffidi Domianello (@simonescaffidi), proprietario del repository. Ogni modifica proposta da altri passa da una pull request revisionata da lui.
  • Approvatori delle release: Simone Scaffidi Domianello (@simonescaffidi).

L'accesso a GitHub e a SignPath è protetto da autenticazione a due fattori.

Privacy

Questo programma non trasferisce informazioni ad altri sistemi in rete se non su richiesta specifica dell'utente o di chi lo installa o lo gestisce. Quando avvii l'app, questa si collega al server di collegamento di Yondesk per ricevere un ID e mettere in contatto i due dispositivi; schermo, file, chat e comandi viaggiano cifrati da un capo all'altro e il server non può leggerli. Se le due reti non si vedono direttamente, il traffico cifrato passa da un relay di Yondesk. Dettagli nella Privacy Policy.

Cosa fa l'app sul dispositivo

  • Nessuna sessione parte senza consenso: l'assistito deve accettare ogni richiesta, e per tutta la sessione resta visibile un avviso.
  • L'accesso non presidiato è spento. Si attiva solo dalle impostazioni, con una password dedicata, e mostra sempre un indicatore.
  • L'app non modifica la configurazione del sistema. Su macOS chiede i permessi Registrazione schermo e Accessibilità tramite le finestre di sistema.

Disinstallazione

  • Windows: Impostazioni → App → App installate → Yondesk → Disinstalla. La versione Portable si elimina cancellando il file.
  • macOS: trascina Yondesk dalla cartella Applicazioni nel Cestino.
  • Linux: sudo apt remove yondesk; l'AppImage si elimina cancellando il file.
  • Android: tieni premuta l'icona → Disinstalla.
