Funzionalità

Potente come i big, trasparente per scelta

Tutto ciò che ti aspetti da uno strumento di assistenza remota professionale.

🖥️ Controllo schermo in tempo reale

Visione e controllo del desktop remoto con latenza minima. Qualità adattiva (bassa/bilanciata/alta) in base alla banda.

🔀 Multi-monitor

Passa da un monitor all'altro del computer remoto e scegli quale visualizzare.

📁 Trasferimento file bidirezionale

Trascina i file nella sessione: viaggiano sul canale cifrato peer-to-peer, senza passare da server o cloud.

💬 Chat di sessione

Messaggistica integrata per coordinarti con l'utente senza strumenti esterni.

📋 Appunti condivisi

Copia su un computer, incolla sull'altro: comodo per password, link e comandi.

🛡️ Accesso non presidiato (opt-in)

Per i tuoi server e PC: lo attivi tu sul dispositivo, con password dedicata e un'icona/banner sempre visibile che segnala l'accesso abilitato.

🔒 Sicurezza

Cifratura end-to-end (DTLS-SRTP), password per sessione, consenso obbligatorio sull'assistito, blocco dopo tentativi errati.

🌐 Multipiattaforma

Windows, macOS, Linux (app desktop), Android e iOS (app mobile) e client web senza installazione.

🔗 Connessione diretta

WebRTC con STUN/TURN: connessione peer-to-peer quando possibile, relay quando serve attraversare i NAT.
