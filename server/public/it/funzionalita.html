Funzionalità

Potente come i big, trasparente per scelta

Tutto ciò che ti aspetti da uno strumento di assistenza remota professionale.

🖥️ Controllo schermo in tempo reale

Visione e controllo di mouse e tastiera del computer remoto con latenza minima, dall'app desktop per Windows, macOS e Linux.

📱 Controllo dal telefono

Dall'app Android o iOS lo schermo del telefono diventa un touchpad: tocco per il clic, pressione lunga per il tasto destro, trascinamento e tastiera.

📁 Trasferimento file bidirezionale

Nel client web invii file in entrambe le direzioni: viaggiano sul canale cifrato peer-to-peer, senza passare da server o cloud.

💬 Chat di sessione

Nel client web, messaggistica integrata per coordinarti con l'utente senza strumenti esterni.

📋 Invio appunti

Copia un testo sul tuo computer e scrivilo su quello remoto con un clic: comodo per link e comandi.

🛡️ Accesso non presidiato (opt-in)

Per i tuoi server e PC: lo attivi tu sul dispositivo, con password dedicata e un'icona/banner sempre visibile che segnala l'accesso abilitato.

🔒 Sicurezza

Cifratura end-to-end (DTLS-SRTP), password per sessione, consenso obbligatorio sull'assistito, blocco dopo tentativi errati.

🌐 Multipiattaforma

Windows, macOS, Linux (app desktop), Android e iOS (app mobile) e client web senza installazione. I diversi client si collegano tra loro; su Android puoi anche condividere lo schermo del telefono.

🔗 Connessione diretta

WebRTC con STUN/TURN: connessione peer-to-peer quando possibile, relay quando serve attraversare i NAT.
